## What I Do

I turn ideas into visuals that get noticed. Social media graphics, ads and print design in **Photoshop** and **Illustrator**, built with a designer's eye for detail and a builder's love for speed.

When a repetitive task slows me down, I build a tool to fix it. That is how most of my tools were born: real problems from real design work, solved once and shared with everyone.

**Design:** Social Media | Ads | Print Design
**Tools of the trade:** Photoshop | Illustrator

## My Tools

Every tool below is free for personal, non-commercial use. Download it, use it, and if you find a bug or have an idea, open a pull request. I read them all.

| Tool | What it does | |
| --- | --- | --- |
| **QuickShot** | Screenshot studio for Windows: capture, scrolling capture, GIF recording and multilingual OCR. | [Repo](https://github.com/moshclusive/quickshot) · [Download v1.2.0](https://github.com/moshclusive/quickshot/releases) |
| **Snapmark** | Full-page screenshots, annotation and vector PDF export, with OCR. Chrome extension. | [Repo](https://github.com/moshclusive/snapmark) |
| **AI Mate** | ChatGPT, Gemini, DeepSeek and Kimi in one Chrome side panel. | [Repo](https://github.com/moshclusive/ai-mate) |
| **Bookly Pro** | New Tab dashboard and bookmark manager for Chrome, with Google Sheets backup. | [Repo](https://github.com/moshclusive/bookly-pro) |
| **Pointera** | Mouse effects for presentations and screen recording: cursor trail, click ripples, spotlight. | [Repo](https://github.com/moshclusive/pointera) · [Download](https://github.com/moshclusive/pointera/releases) |
| **MosHover** | Hover previews for Windows Explorer: images, PDFs, PSDs, videos and archives. | [Repo](https://github.com/moshclusive/moshover) · [Download](https://github.com/moshclusive/moshover/releases) |
| **MoodBox** | Design reference boards, clipboard history and quick launcher. Desktop app + Chrome extension. | [Repo](https://github.com/moshclusive/moodbox) · [Download](https://github.com/moshclusive/moodbox/releases) |
| **Pexora** | Desktop prompt workspace for organizing AI prompts, with local backup and Sheets sync. | [Repo](https://github.com/moshclusive/pexora) · [Download](https://github.com/moshclusive/pexora/releases) |

> Desktop tools have a ready-to-use download under **Releases**. Extensions install by loading unpacked from Chrome. Every repo also has the full source, so you can look under the hood or contribute.
